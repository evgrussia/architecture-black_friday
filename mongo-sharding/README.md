# mongo-sharding

Проект с MongoDB в режиме шардирования: два шарда (rs1, rs2), config server и mongos. Приложение подключается к mongos.

## Как запустить

### 1. Запуск сервисов MongoDB (config server и шарды)

Сначала поднимаются только config server и оба шарда — mongos не сможет стартовать, пока config server не инициализирован как replica set.

```shell
docker compose up -d configsrv shard1 shard2
```

Подождите 10–15 секунд, чтобы процессы mongod поднялись.

### 2. Инициализация config server

Config server должен быть инициализирован как replica set (требование MongoDB 5+ для шардирования):

```shell
./scripts/init-configsrv.sh
```

### 3. Инициализация replica set на каждом шарде

Каждый шард в кластере должен быть replica set (хотя бы с одним узлом):

```shell
./scripts/init-shard1.sh
./scripts/init-shard2.sh
```

Подождите 5–10 секунд после инициализации шардов.

### 4. Запуск mongos и приложения

После инициализации config server и шардов можно запускать роутер и приложение:

```shell
docker compose up -d mongos pymongo_api
```

Подождите несколько секунд, пока mongos подключится к config server.

### 5. Регистрация шардов и включение шардирования

Через mongos добавляются шарды в кластер, включается шардирование для БД `somedb` и коллекции `helloDoc`:

```shell
./scripts/init-mongos.sh
```

### 6. Наполнение базы данными

Вставка документов выполняется через mongos (данные распределяются по шардам):

```shell
./scripts/mongo-init.sh
```

Скрипт создаёт в БД `somedb` коллекцию `helloDoc` и вставляет 1000 документов.

## Одной командой (после первого запуска)

Если контейнеры уже были подняты и инициализация выполнялась ранее, для повторного запуска достаточно:

```shell
docker compose up -d
```

Данные сохраняются в томах Docker.

## Как проверить

- **Локально:** откройте в браузере http://localhost:8080  
- **На ВМ:** откройте http://\<IP виртуальной машины\>:8080  

На главной странице приложение возвращает JSON с типом топологии (`Sharded`), списком шардов и количеством документов по коллекциям. Ожидается не менее 1000 документов в базе и отображение обоих шардов.

## Состав кластера

| Сервис      | Назначение                          |
|------------|--------------------------------------|
| configsrv  | Config server (replica set), порт 27019 |
| shard1     | Шард 1 (replica set rs1), порт 27018 |
| shard2     | Шард 2 (replica set rs2), порт 27018 |
| mongos     | Роутер запросов, порт 27017         |
| pymongo_api| Приложение, подключается к mongos    |

БД: `somedb`, коллекция: `helloDoc`.
